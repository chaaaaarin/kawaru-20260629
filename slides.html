軸②：プロンプトキャッシュを活かす ✅

キャッシュとは

会話の「上部」（システムプロンプト・AGENTS.md・Skills）は
同一であれば自動的にキャッシュ。

キャッシュ済みトークン ≒ 通常の10%コスト ✅
→ 3,000トークンの AGENTS.md も30ターンで
　 初回全額 + 29回×10% に圧縮される

キャッシュを壊さないために

  • ○ セッション中は AGENTS.md を変更しない
  • ○ MCPサーバーを途中で追加・削除しない
  • ○ 静的な設定を先頭に、動的なメッセージを末尾に
  • × セッション中に設定を「ちょっと直す」→ キャッシュ全リセット

③

軸③：並列エージェント vs 逐次 — 使い分け ✅

並列（独立タスクに使う）
  • 各エージェントが独立した Git worktree で動作 → 衝突なし ✅
  • 「バックエンドAPI実装」「フロントエンドUI」「統合テスト」を同時進行
  • 独立していれば並列で時間短縮 ○
vs
逐次（共有コンテキストに使う）
  • 前のステップの結果を次のステップに渡せる
  • コンテキストを共有するタスクは逐次の方が精度が高い
  • 並列4→逐次1で 40%削減の事例 🔶

⚠️ 並列エージェントはそれぞれが独立したコンテキストをフルでロードする。起動コストが高いので、タスクが小さい場合は逐次の方が安い。
